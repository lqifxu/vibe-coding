# 极速下 — 部署上线指南（Docker）

本仓库已提供 `docker-compose.yml`，可在一台 Linux 服务器上一键启动 **前端 + API（含 ffmpeg）**。

## 你需要准备

1. 一台云服务器（推荐 Ubuntu 22.04，2 核 4G+）
2. 域名（A 记录指向服务器公网 IP；没有域名可先用 IP 测）
3. 服务器已安装 Docker + Docker Compose 插件
4. Stripe 密钥（测试用 `sk_test_`，正式收款用 `sk_live_`）

> 我（AI）无法在没有 SSH 账号的情况下替你登录云厂商后台。把 **IP / 用户名 / 登录方式** 发给我后，才能代你在机器上执行部署。

## 一键部署步骤

### 1. 安装 Docker（Ubuntu 示例）

```bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
# 重新登录 SSH 使 docker 组生效
```

### 2. 拉代码

```bash
sudo mkdir -p /opt/jisuxia
sudo chown "$USER":"$USER" /opt/jisuxia
git clone <你的仓库地址> /opt/jisuxia
cd /opt/jisuxia
```

### 3. 填写环境变量

```bash
mkdir -p deploy/data deploy/temp
cp deploy/.env.example deploy/.env
nano deploy/.env
```

必改项：

| 变量 | 说明 |
|------|------|
| `PUBLIC_APP_URL` | `https://你的域名` |
| `VITE_SITE_URL` | 同上（构建进前端） |
| `JWT_SECRET` | 长随机串 |
| `COOKIE_SECURE` | HTTPS 时为 `true` |
| `LLM_API_KEY` | DeepSeek 等 |
| `ASR_API_KEY` / `ASR_BASE_URL` / `ASR_MODEL` | 抖音、小红书，以及没有字幕轨的 YouTube（云端转写；见 `deploy/.env.example`） |
| `STRIPE_*` | Secret / Webhook / Price |

> `VITE_SITE_URL` 在 **构建镜像时** 生效。改域名后需重新 `docker compose build web`。

### 4. 启动

```bash
cd /opt/jisuxia
chmod +x deploy/up.sh
./deploy/up.sh
```

或手动：

```bash
export VITE_SITE_URL=https://你的域名
docker compose --env-file deploy/.env up -d --build
```

检查：

```bash
docker compose ps
curl -s http://127.0.0.1/api/health
```

浏览器访问：`http://服务器IP` 或域名（若已解析）。

### 5. HTTPS（推荐 Caddy）

若 `HTTP_PORT=80`，可在宿主机装 Caddy 自动证书：

```bash
sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https
# 按 https://caddyserver.com/docs/install#debian-ubuntu-raspbian 安装 caddy
```

`/etc/caddy/Caddyfile`：

```caddy
你的域名 {
    reverse_proxy 127.0.0.1:80
}
```

```bash
sudo systemctl reload caddy
```

然后确认 `deploy/.env` 里：

```env
PUBLIC_APP_URL=https://你的域名
VITE_SITE_URL=https://你的域名
COOKIE_SECURE=true
```

并重建前端：

```bash
export VITE_SITE_URL=https://你的域名
docker compose up -d --build web
docker compose restart api
```

### 6. Stripe 正式 Webhook

1. Dashboard → **Live**（或 Test）→ Developers → Webhooks → Add endpoint  
2. URL：`https://你的域名/api/billing/webhook`  
3. 勾选：`checkout.session.completed`、`customer.subscription.created/updated/deleted`、`invoice.payment_failed`  
4. 复制 `whsec_...` → `deploy/.env` 的 `STRIPE_WEBHOOK_SECRET`  
5. Settings → Billing → Customer portal 启用  
6. `docker compose restart api`

本地 `stripe listen` **仅开发用**，线上必须用 Dashboard endpoint。

## 宝塔面板部署（推荐你这种场景）

宝塔已装好时，用 **「网站静态 + 反向代理 + 守护进程跑 API」** 最省事（不必强依赖 Docker）。  
腾讯云轻量 + OpenCloudOS 9 已按此方式验证通过（公网 IP 访问即可，不必先有域名）。

### A. 面板里先装软件

软件商店安装：

- Nginx
- 「进程守护管理器」（或 Supervisor）
- （可选）Docker（若你更想用 compose）

系统依赖（OpenCloudOS / CentOS 用 `dnf`，Debian/Ubuntu 用 `apt`）：

```bash
# OpenCloudOS 9 / 腾讯云轻量常见
dnf install -y ffmpeg nodejs python3-pip python3-devel git

# Debian/Ubuntu
# sudo apt update && sudo apt install -y python3 python3-venv python3-pip ffmpeg git nodejs
```

确认：`ffmpeg -version`、`node -v`、`python3 -V`（建议 3.10+）。  
**不要**安装 Playwright；本项目抖音/小红书不依赖它。

### B. 上传 / 拉取代码

建议目录：

```text
/www/wwwroot/jisuxia/
  backend/
  frontend/
```

```bash
cd /www/wwwroot
git clone <仓库地址> jisuxia
```

国内轻量机访问 `github.com:443` 经常超时。失败时在本机打包源码（排除 `.venv`、`node_modules`、`dist`），用宝塔「文件」上传到 `/www/wwwroot/jisuxia` 再解压。

### C. 后端环境

```bash
cd /www/wwwroot/jisuxia/backend
python3 -m venv .venv
.venv/bin/pip install -U pip -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
.venv/bin/pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
cp .env.example .env
mkdir -p data temp
```

清华源若出现 `from versions: none`，改用上面的阿里云 / 腾讯云 PyPI 镜像。

`.env` 关键：

```env
# 仅有公网 IP、尚未 HTTPS 时：
PUBLIC_APP_URL=http://你的公网IP
COOKIE_SECURE=false
DATABASE_PATH=/www/wwwroot/jisuxia/backend/data/app.db
JWT_SECRET=很长的随机串
LLM_API_KEY=...
ASR_PROVIDER=api
ASR_BASE_URL=https://api.siliconflow.cn/v1
ASR_API_KEY=...
ASR_MODEL=FunAudioLLM/SenseVoiceSmall
FREE_DAILY_SUMMARIES=10
FREE_DAILY_PARSES=10
# Stripe 可先空着；有域名并上 HTTPS 后再配
```

有正式域名并启用 HTTPS 后，再把 `PUBLIC_APP_URL` 改成 `https://域名`，`COOKIE_SECURE=true`。

用宝塔 **进程守护管理器** 添加进程：

| 项 | 值 |
|---|---|
| 名称 | jisuxia-api |
| 启动用户 | root（写 `data/` / `temp/` 更省事） |
| 运行目录 | `/www/wwwroot/jisuxia/backend` |
| 启动命令 | `/www/wwwroot/jisuxia/backend/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8001` |

若状态 FATAL：先 `pkill -f "uvicorn app.main:app"` 清掉占用 8001 的旧进程，再点「启动」。  
本机测：`curl -s http://127.0.0.1:8001/api/health`（应含 `"ok":true`、`"ffmpeg":true`）。  
**不要**在轻量防火墙放行 8001，只由 Nginx 反代。

### D. 前端构建

服务器内存约 2G 时，`npm run build` 可能偏紧；可在本机构建后只上传 `dist`。

本机（Windows PowerShell 若拦截 `npm.ps1`，用 `npm.cmd`）：

```powershell
cd frontend
Set-Content -Path .env -Value "VITE_SITE_URL=http://你的公网IP"
npm.cmd install --registry=https://registry.npmmirror.com
npm.cmd run build
```

服务器上构建：

```bash
cd /www/wwwroot/jisuxia/frontend
echo "VITE_SITE_URL=http://你的公网IP" > .env
npm install --registry=https://registry.npmmirror.com
npm run build
# 产物：frontend/dist
```

### E. 宝塔添加网站

1. **网站 → HTML 项目 → 添加项目**  
   - 域名：公网 IP 或已解析域名  
   - 根目录：`/www/wwwroot/jisuxia/frontend/dist`  

2. **设置 → 配置文件**：整段 `server { }` 示例（第一行只能是 `server {`，不要写成 `server server {`）：

```nginx
server {
    listen 80;
    server_name 你的公网IP或域名;

    location / {
        root /www/wwwroot/jisuxia/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
    }
}
```

后端端口是 **8001**（不是 8000）。保存后重载 Nginx。

3. 验收：浏览器打开 `http://IP/` 与 `http://IP/api/health`。

4. 有域名后：**SSL** → Let’s Encrypt → 强制 HTTPS，并按上一节改 `.env` / 前端 `VITE_SITE_URL` 后重新 build。

### F. Stripe

Webhook 填：`https://你的域名/api/billing/webhook`  
`PUBLIC_APP_URL` / `VITE_SITE_URL` 都用 `https://你的域名`，改完重启 Supervisor 里的 API，并视情况重新 `npm run build`。

### G. 给我代操作时发这些即可

```text
服务器 IP：
SSH 端口：22（或宝塔改过的）
SSH 用户：root
密码：****（或密钥）
宝塔面板地址/端口：（可选，有 SSH 通常够用）
域名：
域名是否已解析到该 IP：是/否
Stripe：Test / Live 密钥是否已准备
```

有 SSH 后我会按上面顺序：装依赖 → 拉代码 → 配 `.env` → Supervisor → 网站/反代/SSL → 验收 `/api/health` 与首页。

## Windows 宝塔部署

Windows 宝塔**没有 Linux 那套 apt/Supervisor**，一般用：

- 网站：Nginx（宝塔安装）
- 后端：本机 Python 虚拟环境 + **NSSM** 或宝塔「进程守护」做成 Windows 服务
- 前端：本机构建 `dist`，网站根目录指向它
- 系统需单独装好：**Python 3.10+、Node 18+、ffmpeg**（并加入 PATH）

> Docker 在 Windows 宝塔上往往更折腾（要 Docker Desktop + WSL2）。Windows 上更建议「原生 Python + Nginx」，不要硬上 Docker。

### 1. 装运行环境

在服务器上安装并确认命令可用（PowerShell / CMD）：

```powershell
python --version
node --version
npm --version
ffmpeg -version
git --version
```

ffmpeg 可放到如 `C:\ffmpeg\bin`，并加入系统 PATH。

### 2. 放代码

建议目录（按你盘符改）：

```text
D:\wwwroot\jisuxia\
  backend\
  frontend\
```

用 Git 克隆，或宝塔「文件」上传解压。

### 3. 后端

```powershell
cd D:\wwwroot\jisuxia\backend
py -3.12 -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
copy .env.example .env
notepad .env
```

`.env` 注意：

```env
PUBLIC_APP_URL=https://你的域名
COOKIE_SECURE=true
DATABASE_PATH=D:/wwwroot/jisuxia/backend/data/app.db
JWT_SECRET=很长随机串
LLM_API_KEY=...
ASR_PROVIDER=api
ASR_BASE_URL=https://api.siliconflow.cn/v1
ASR_API_KEY=...
ASR_MODEL=FunAudioLLM/SenseVoiceSmall
STRIPE_SECRET_KEY=...
STRIPE_WEBHOOK_SECRET=...
STRIPE_PRICE_ID=...
```

先手动试跑：

```powershell
.\.venv\Scripts\uvicorn.exe app.main:app --host 127.0.0.1 --port 8001
```

浏览器或本机访问：`http://127.0.0.1:8001/api/health`。

再用 **NSSM**（或宝塔进程守护）注册为服务，启动命令示例：

```text
路径: D:\wwwroot\jisuxia\backend\.venv\Scripts\uvicorn.exe
参数: app.main:app --host 127.0.0.1 --port 8001
目录: D:\wwwroot\jisuxia\backend
```

### 4. 前端

```powershell
cd D:\wwwroot\jisuxia\frontend
echo VITE_SITE_URL=https://你的域名> .env
npm install --registry=https://registry.npmmirror.com
npm run build
```

产物目录：`D:\wwwroot\jisuxia\frontend\dist`

### 5. 宝塔网站 + 反代

1. 网站 → 添加站点 → 域名填好 → 根目录选 `...\frontend\dist`
2. 设置 → 反向代理：把 **`/api`** 转到 `http://127.0.0.1:8001`
3. 配置文件中确认有 SPA 回退与长超时，例如：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8001;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_buffering off;
    proxy_read_timeout 600s;
}

location / {
    try_files $uri $uri/ /index.html;
}
```

4. SSL：宝塔申请证书并强制 HTTPS  
5. 防火墙 / 安全组放行 80、443（以及你用的远程桌面端口）

### 6. Stripe

Webhook：`https://你的域名/api/billing/webhook`（不要用 `localhost`）。
