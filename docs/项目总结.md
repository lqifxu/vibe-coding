# 极速下 — 项目总结

> 万能视频下载网站 + 同页 AI 视频总结（本地验收沉淀）

## 1. 背景与目标

很多平台不提供便捷下载，或清晰度/批量受限。本项目目标做一个**轻量、可手机使用**的网页工具：粘贴链接或分享口令 → 解析清晰度 → 下载到本地；并在同一结果区提供 **AI 学习笔记**（总结 / 字幕 / 导图 / 问答）。

产品原则：

- UI 突出实用与付费转化（仿鱼皮 AI 绘图站风格）
- 后端轻量、**无数据库**
- 下载能力站在开源肩膀上（yt-dlp），不自研各平台协议
- **不向用户索要 Cookie** 作为默认路径（B 站可选 Cookie 仅作人工 CC 增强）
- **开闭原则**：下载核心保持稳定；AI 总结以扩展模块挂载

## 2. 技术选型

| 层 | 方案 | 说明 |
|---|---|---|
| 下载引擎 | yt-dlp（Python API） | 覆盖上千站点 |
| 抖音专项 | iesdouyin 分享页解析 | 无 Cookie，绕过 yt-dlp Douyin 强依赖 Cookie 的路径 |
| 后端 | FastAPI + uvicorn | 下载路由 + `summary_router` 扩展 |
| LLM | OpenAI Python SDK + DeepSeek 默认 | 流式总结 / 问答 |
| 前端 | Vite + React + TS + Tailwind | 落地页；`/api` 代理 → `:8001` |
| SEO | On-page + 可抓取内容区 | `VITE_SITE_URL` 驱动 canonical/OG/robots/sitemap；无 SSR |
| 音视频合并 | ffmpeg | `backend/ffmpeg.path` 或 `FFMPEG_PATH` |

## 3. 架构与核心流程

### 3.1 下载

```
用户粘贴口令/链接
    → 提取 http(s) URL（分享文案混贴）
    → 若为抖音：提取 video_id / modal_id → iesdouyin 分享页 → play 直链
    → 其他平台：yt-dlp extract_info / download
    → 临时目录落盘 → FileResponse 触发浏览器下载 → 后台清理
```

### 3.2 AI 总结（扩展）

```
解析成功 →（LLM 已配置时）自动 POST /api/summarize
    → 拉字幕（yt-dlp / B 站 dm/view AI 字幕等）
    → LLM 流式 Markdown → SSE 推前端
    → 左右同屏：左下载 / 右文档式四模块摘要（无时间线）+ cues + 彩色 mindmap(PNG) + 可问答

解析成功 →「下载字幕」（可选，不跑 LLM）
    → POST /api/subtitles → SRT / VTT / TXT
```

关键代码：

- `backend/app/main.py` — 下载 HTTP；`include_router(summary_router)`
- `backend/app/ytdlp_service.py` — yt-dlp 封装、URL 规范化
- `backend/app/douyin_service.py` — 抖音无 Cookie 解析与下载
- `backend/app/summary_*.py` / `subtitle_service.py` / `llm_service.py` — 总结扩展
- `frontend/src/summary/` — 同屏总结 UI（`SplitResultShell` + `VideoResultSection`）

详情见 [AI视频总结方案.md](./AI视频总结方案.md)。

## 4. 抖音能力（重点）

支持输入：

1. **分享口令**（文案中含 `https://v.douyin.com/...` 或 `/video/{id}`）
2. **标准页** `https://www.douyin.com/video/{数字ID}`
3. **网页弹窗地址** `...?modal_id={数字ID}`（如精选页）

不支持（会明确报错）：

- 浏览器推荐页首页，如 `https://www.douyin.com/?recommend=1`（**不含视频 ID**）

方案取舍：

- 否：用户自填 Cookie / 公共号 Cookie / 扫码登录泄密（下载路径）
- 否：仅浏览器插件（不符合网站服务形态）
- 是：服务端用移动端 UA 打开分享页解析直链

说明：抖音目前**不做 AI 总结**（缺可用字幕链路）。

## 9. 已知限制与后续

**限制**

- 无数据库，配额为内存级 IP 限流，重启即清空
- 大文件占用服务器临时磁盘与带宽，适合演示/小流量
- 部分平台风控仍可能导致失败
- 无 ASR：完全没有字幕的视频无法总结
- 本地默认后端端口以 `vite` 代理为准（当前常为 **8001**）
- SPA 无 SSR：部分不执行 JS 的爬虫主要依赖 `index.html` meta 与 `noscript`；正式收录需配置真实域名并提交 sitemap

**可后续扩展**

- 真实支付与会员配额
- 批量下载队列
- 字幕翻译（Pro 占位）
- ASR 语音转写
- 问答多轮持久化、导图主题与更多导出格式
- 程序化 SEO 落地页（如「B站视频下载」独立页）
- SSR/SSG（如需进一步强化百度抓取）
