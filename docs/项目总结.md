# 极速下 — 项目总结

> 万能视频下载网站 MVP 沉淀文档（截至本地验收完成）

## 1. 背景与目标

很多平台不提供便捷下载，或清晰度/批量受限。本项目目标做一个**轻量、可手机使用**的网页工具：粘贴链接或分享口令 → 解析清晰度 → 下载到本地。

产品原则：

- UI 突出实用与付费转化（仿鱼皮 AI 绘图站风格）
- 后端轻量、**无数据库**
- 下载能力站在开源肩膀上（yt-dlp），不自研各平台协议
- **不向用户索要 Cookie**，不做扫码登录拿登录态，不提供公共号 Cookie

## 2. 技术选型

| 层 | 方案 | 说明 |
|---|---|---|
| 下载引擎 | yt-dlp（Python API） | 覆盖上千站点 |
| 抖音专项 | iesdouyin 分享页解析 | 无 Cookie，绕过 yt-dlp Douyin 强依赖 Cookie 的路径 |
| 后端 | FastAPI + uvicorn | `/api/info`、`/api/download`、`/api/health` |
| 前端 | Vite + React + TS + Tailwind | 转化型落地页，开发代理 `/api` → `:8000` |
| 音视频合并 | ffmpeg | 通过 `backend/ffmpeg.path` 或环境变量 `FFMPEG_PATH` 指定 |

## 3. 架构与核心流程

```
用户粘贴口令/链接
    → 提取 http(s) URL（分享文案混贴）
    → 若为抖音：提取 video_id / modal_id → iesdouyin 分享页 → play 直链
    → 其他平台：yt-dlp extract_info / download
    → 临时目录落盘 → FileResponse 触发浏览器下载 → 后台清理
```

关键代码：

- `backend/app/main.py` — HTTP 路由、限流
- `backend/app/ytdlp_service.py` — yt-dlp 封装、URL 规范化
- `backend/app/douyin_service.py` — 抖音无 Cookie 解析与下载
- `frontend/src/` — 落地页与 API 调用

## 4. 抖音能力（重点）

支持输入：

1. **分享口令**（文案中含 `https://v.douyin.com/...` 或 `/video/{id}`）
2. **标准页** `https://www.douyin.com/video/{数字ID}`
3. **网页弹窗地址** `...?modal_id={数字ID}`（如精选页）

不支持（会明确报错）：

- 浏览器推荐页首页，如 `https://www.douyin.com/?recommend=1`（**不含视频 ID**）

方案取舍（与产品思考一致）：

- 否：用户自填 Cookie / 公共号 Cookie / 扫码登录泄密
- 否：仅浏览器插件（不符合网站服务形态）
- 是：服务端用移动端 UA 打开分享页解析直链（开源常见做法）

## 5. ffmpeg

- 未配置时：部分「需合并音轨」的高清格式不可用，可下「仅画面」或带音轨格式
- 配置方式：在 `backend/ffmpeg.path` 写入 ffmpeg 所在 **bin 目录**路径，或设置环境变量 `FFMPEG_PATH`
- 该文件已加入 `.gitignore`，避免把本机路径提交进仓库

## 6. 已验收结果（开发机）

| 场景 | 结果 |
|---|---|
| 公开 MP4 直链 | 解析 + 下载成功 |
| 抖音 `/video/{id}`、分享口令提取 | 成功 |
| 抖音 `jingxuan?modal_id=...` | 解析 + 下载成功（约 9MB+） |
| B 站 + ffmpeg 合并音轨 | 成功（如 360p 合并约 14MB） |
| `/api/health` | 可检测 yt-dlp / ffmpeg |
| 无视频 ID 的推荐页 | 友好错误提示 |

说明：YouTube 等在部分网络环境下可能超时，属环境限制，非核心逻辑缺陷。

## 7. 已知限制与后续

**限制**

- 无数据库，配额为内存级 IP 限流，重启即清空
- 大文件占用服务器临时磁盘与带宽，适合演示/小流量
- 部分平台风控仍可能导致失败

**可后续扩展**

- 真实支付与会员配额
- 批量下载队列
- 字幕翻译、AI 视频总结（当前仅为 Pro 入口占位）
